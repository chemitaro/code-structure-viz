# Root-cause groups

## RG-SI04-01 — reverse failure closure と public File projection の照合欠落

**Mapped items**

- `R1`, source-native classification `P1`
- `CG-SI04-01`, nonprogram reverse importer の回帰 coverage 欠落

**Shared invariant.** `parse_file`／`read_file` failure の reverse closure に属する File が、合法な owner-closed partition 後も available public File projection に残る場合、その subset は独立とは立証されていない。File taint、偽 Module、逆 causal edgeを発明せず、Core locality を `false` として `CSV-NEXT-SOURCE-003`／payload unavailable に閉じなければならない。

## RG-SI04-02 — ordinary open-edge 判定で forward と reverse を一つの集合に潰している

**Mapped items**

- `R2`, source-native classification `P2`
- `CG-SI04-02`, fully Core-valid compound fixture／fresh execution の欠落

**Shared invariant.** 通常 open edge の locality impact は failed File からの forward reachability 上で評価し、`module_plane` のみを graph-global fail-closed とする。reverse failure closure は importer の除外・安全 projection 判定に使うが、その importer が持つ独立した通常 open edgeを、それだけで failed File の nonlocal dependency としてはならない。

**Root cause.** Current implementation は `affected = forward closure ∪ reverse closure` とし、通常 open edge の source がこの union に入るだけで `open_dependency=true` とする。このため forward dependency と reverse invalidation の意味が失われている。

## Deliberate non-grouping

RG-SI04-01 と RG-SI04-02 は同じ helper 内にあり、広義には retained ledger semantics の不完全な移植という共通背景を持つ。しかし、次の理由で一群にはしない。

- R1 は public File projection との交差 predicate を追加するだけで、R2 の open-edge predicate を変更せず修正できる。
- 一群にすると P1 authorization を利用して P2 behavior まで暗黙に変更する危険がある。
